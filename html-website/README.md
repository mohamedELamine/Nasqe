# موقع نسق - Nasqe Website

موقع HTML ثابت جاهز للتشغيل مباشرة - حلول رقمية متكاملة

## 📦 المحتويات

```
nasqe-website/
├── index.html          # الصفحة الرئيسية
├── about.html          # صفحة من نحن
├── services.html       # صفحة الخدمات
├── portfolio.html      # صفحة الأعمال
├── contact.html        # صفحة التواصل
├── css/
│   └── style.css       # ملف الأنماط الرئيسي
├── js/
│   └── main.js         # ملف JavaScript الرئيسي
├── images/             # مجلد الصور
└── README.md          # هذا الملف
```

## 🚀 كيفية التشغيل

### الطريقة الأولى: فتح مباشر
1. افتح ملف `index.html` في المتصفح
2. انتهى! الموقع جاهز للعمل

### الطريقة الثانية: خادم محلي
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام PHP
php -S localhost:8000

# أو باستخدام Node.js (مع npx)
npx http-server
```

ثم افتح `http://localhost:8000` في المتصفح

## 🎨 التخصيص

### تغيير الألوان
افتح `css/style.css` وعدّل المتغيرات:

```css
:root {
    --primary-dark-green: #1a4d3e;
    --primary-green: #2d6a4f;
    --secondary-orange: #ff8c42;
    --bg-light: #f8f9fa;
    --text-dark: #1a1a1a;
    --text-gray: #6b7280;
}
```

### تعديل المحتوى
- افتح أي ملف HTML
- ابحث عن النص الذي تريد تغييره
- عدّل النص مباشرة
- احفظ الملف

### إضافة صور
1. ضع الصور في مجلد `images/`
2. استخدمها في HTML:
```html
<img src="images/your-image.jpg" alt="الوصف">
```

## 🔧 نموذج التواصل

النموذج الحالي يعرض رسالة تأكيد بسيطة. لربطه بخادم حقيقي:

### خيار 1: FormSpree (مجاني)
```html
<form action="https://formspree.io/f/YOUR_ID" method="POST">
```

### خيار 2: Netlify Forms
```html
<form name="contact" netlify>
```

### خيار 3: PHP
أنشئ ملف `send-email.php` وعدّل action في النموذج.
