# دليل استيراد المحتوى التجريبي

<div dir="rtl">

## 📦 استيراد المحتوى التجريبي

يتضمن القالب ملف محتوى تجريبي جاهز للاستيراد `demo-content.xml` يحتوي على:

- ✅ 5 صفحات جاهزة (الرئيسية، من نحن، الخدمات، الأعمال، تواصل معنا)
- ✅ 2 مقالات تجريبية
- ✅ تصنيفات ووسوم

---

## 🚀 خطوات الاستيراد

### الطريقة 1: عبر أداة Import (موصى بها)

#### 1. تثبيت أداة WordPress Importer

```
الأدوات → استيراد → WordPress
اضغط على "تثبيت الآن" ثم "تشغيل الأداة"
```

#### 2. اختيار ملف الاستيراد

```
اضغط "Choose File"
اختر ملف: demo-content.xml
اضغط "Upload file and import"
```

#### 3. تعيين المؤلف

```
- اختر مستخدم موجود أو أنشئ مستخدم جديد
- ✅ تأكد من تحديد "Download and import file attachments" لاستيراد الصور
```

#### 4. انتظر حتى يكتمل الاستيراد

```
ستظهر رسالة: "All done. Have fun!"
```

---

### الطريقة 2: استيراد يدوي (للمتقدمين)

إذا كنت تريد إنشاء الصفحات يدوياً:

#### 1. إنشاء الصفحات

أنشئ 5 صفحات جديدة:

**الصفحة الأولى: الرئيسية**
```
العنوان: الرئيسية
القالب: الصفحة الرئيسية (Home Page)
المحتوى: [اختر قالب "الصفحة الرئيسية" من الشريط الجانبي]
```

**الصفحة الثانية: من نحن**
```
العنوان: من نحن
القالب: صفحة من نحن (About Page)
```

**الصفحة الثالثة: خدماتنا**
```
العنوان: خدماتنا
القالب: صفحة الخدمات (Services Page)
```

**الصفحة الرابعة: أعمالنا**
```
العنوان: أعمالنا
القالب: صفحة الأعمال (Portfolio Page)
```

**الصفحة الخامسة: تواصل معنا**
```
العنوان: تواصل معنا
القالب: صفحة التواصل (Contact Page)
```

#### 2. تعيين الصفحة الرئيسية

```
الإعدادات → القراءة
صفحة رئيسية ثابتة → اختر "الرئيسية"
احفظ التغييرات
```

---

## 🎨 استخدام Block Patterns

بدلاً من استيراد المحتوى، يمكنك بناء الصفحات باستخدام Block Patterns الجاهزة:

### 1. أنشئ صفحة جديدة

```
الصفحات → إضافة جديد
```

### 2. أضف الأنماط (Patterns)

اضغط زر **+** → **Patterns** → ابحث عن "نسق"

**للصفحة الرئيسية:**
1. قسم البطل (Hero Section)
2. شبكة الخدمات (Services Grid)
3. دعوة للعمل (CTA Section)

**لصفحة من نحن:**
1. قسم الفريق (Team Section)

**لصفحة الأعمال:**
1. شبكة الأعمال (Portfolio Grid)
2. آراء العملاء (Testimonials)

---

## 📝 بعد الاستيراد

### 1. ضبط القائمة الرئيسية

```
المظهر → القوائم
أنشئ قائمة جديدة
أضف الصفحات: الرئيسية، من نحن، الخدمات، الأعمال، تواصل
الموقع: Primary Navigation
احفظ القائمة
```

### 2. رفع الشعار

```
المظهر → تخصيص → هوية الموقع
اختر شعار
الحجم الموصى: 200×80 بكسل
```

### 3. ضبط الروابط الدائمة

```
الإعدادات → الروابط الدائمة
اختر: اسم المقال
احفظ التغييرات
```

## ⚠️ ملاحظات مهمة

### الصور التجريبية

- الصور في الملف التجريبي هي روابط من Unsplash
- ستعمل مباشرة ولكن يُنصح باستبدالها بصورك الخاصة
- لتحميل الصور: تأكد من تحديد "Download attachments" عند الاستيراد

### المحتوى العربي

- جميع المحتوى باللغة العربية
- القالب يدعم RTL بشكل كامل
- الخط المستخدم: Cairo من Google Fonts

### التخصيص

بعد الاستيراد، يمكنك تخصيص:
- الألوان من: المظهر → المحرر → الأنماط
- المحتوى من: محرر الصفحات
- الإعدادات من: theme.json

## 🔧 حل المشاكل

### المشكلة: لا تظهر القوالب

**الحل:**
1. تأكد من تفعيل القالب
2. امسح الكاش
3. تأكد من وجود ملف theme.json

### المشكلة: الصور لا تظهر

**الحل:**
1. تأكد من اختيار "Download attachments"
2. تحقق من الاتصال بالإنترنت
3. جرب رفع الصور يدوياً

### المشكلة: المحتوى فارغ

**الحل:**
1. تأكد من اختيار القالب الصحيح للصفحة
2. افتح الصفحة في المحرر
3. تأكد من وجود المحتوى
