# دليل التثبيت السريع - قالب نسق

<div dir="rtl">

## 📦 خطوات التثبيت (5 دقائق)

### 1️⃣ رفع القالب إلى ووردبريس

#### الطريقة الأولى: عبر لوحة التحكم

1. اضغط المجلد `nasqe-theme` في ملف ZIP
2. اذهب إلى: **المظهر → القوالب → إضافة جديد**
3. انقر على **رفع قالب**
4. اختر الملف واضغط **التثبيت الآن**
5. انقر **تفعيل**

#### الطريقة الثانية: عبر FTP

1. ارفع مجلد `nasqe-theme` إلى:
   ```
   wp-content/themes/nasqe-theme/
   ```
2. اذهب إلى: **المظهر → القوالب**
3. انقر **تفعيل** على قالب نسق

---

### 2️⃣ إعداد أساسي (3 دقائق)

#### رفع الشعار
```
المظهر → تخصيص → هوية الموقع → اختيار شعار
```
- الحجم الموصى به: 200×80 بكسل
- الصيغة: PNG أو SVG

#### إنشاء القائمة الرئيسية
```
المظهر → القوائم → إنشاء قائمة جديدة
```
- الاسم: "القائمة الرئيسية"
- الموقع: Primary Navigation
- أضف الصفحات: الرئيسية، الخدمات، الأعمال، من نحن، تواصل معنا

---

### 3️⃣ إنشاء الصفحة الرئيسية

1. **إنشاء صفحة جديدة:**
   ```
   الصفحات → إضافة جديد
   ```
   - العنوان: "الرئيسية"

2. **اختيار القالب:**
   - من الشريط الجانبي → **القالب** → اختر "الصفحة الرئيسية"

3. **أو بناء صفحة مخصصة باستخدام Patterns:**
   - اضغط على زر **+** لإضافة بلوك
   - اختر **Patterns**
   - ابحث عن "نسق"
   - أضف الأنماط بالترتيب:
     1. قسم البطل (Hero Section)
     2. شبكة الخدمات (Services Grid)
     3. دعوة للعمل (CTA Section)

4. **نشر الصفحة**

5. **تعيينها كصفحة رئيسية:**
   ```
   الإعدادات → القراءة → صفحة رئيسية ثابتة → اختر "الرئيسية"
   ```

---

### 4️⃣ إعدادات موصى بها

#### الروابط الدائمة
```
الإعدادات → الروابط الدائمة → اسم المقال
```

#### إعدادات الوسائط
```
الإعدادات → الوسائط
```
- حجم متوسط: 800×600
- حجم كبير: 1200×800

#### إعدادات عامة
```
الإعدادات → عام
```
- ✅ تأكد من ضبط المنطقة الزمنية
- ✅ تأكد من ضبط اللغة إلى العربية

---

### 5️⃣ إضافات موصى بها

لتحسين أداء الموقع:

#### للأداء:
- **WP Rocket** أو **W3 Total Cache** - للتخزين المؤقت
- **ShortPixel** - لضغط الصور
- **WP-Optimize** - لتنظيف قاعدة البيانات

#### للأمان:
- **Wordfence Security** - للحماية
- **UpdraftPlus** - للنسخ الاحتياطي

#### للـ SEO:
- **Rank Math** أو **Yoast SEO** - لتحسين محركات البحث

---

### 6️⃣ اختبار الموقع

بعد التثبيت، تأكد من:

- ✅ الصفحة الرئيسية تظهر بشكل صحيح
- ✅ القائمة تعمل
- ✅ الشعار يظهر
- ✅ الروابط تعمل
- ✅ التصميم متجاوب على الموبايل

**اختبر على:**
- 💻 سطح المكتب
- 📱 الموبايل
- 🖥️ التابلت

## 🎨 تخصيص سريع

### تغيير الألوان

1. اذهب إلى: **المظهر → المحرر**
2. انقر على **الأنماط** (Styles)
3. اختر **الألوان** (Colors)
4. عدّل الألوان حسب رغبتك

### تغيير الخطوط

في ملف `theme.json`:
```json
"typography": {
  "fontFamilies": [
    {
      "fontFamily": "'خطك المفضل', sans-serif",
      "slug": "custom-font"
    }
  ]
}
```
