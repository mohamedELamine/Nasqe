## 📥 تحميل القالب

الملف الجاهز للتثبيت: `nasqe-theme.zip`

---

## ⚡ تثبيت سريع (دقيقتان)

### الطريقة 1: عبر لوحة التحكم (موصى بها)

```
1. لوحة التحكم → المظهر → القوالب → إضافة جديد
2. رفع قالب → اختر nasqe-theme.zip
3. التثبيت الآن → تفعيل
✅ تم!
```

### الطريقة 2: عبر FTP

```
1. فك ضغط nasqe-theme.zip
2. ارفع مجلد nasqe-theme إلى: wp-content/themes/
3. المظهر → القوالب → تفعيل "نسق"
✅ تم!
```

---

## 🎨 إعداد أساسي (3 دقائق)

### 1. رفع الشعار
```
المظهر → تخصيص → هوية الموقع → اختيار شعار
الحجم الموصى: 200×80 بكسل
```

### 2. إنشاء القائمة
```
المظهر → القوائم → إنشاء قائمة جديدة
الاسم: "القائمة الرئيسية"
الموقع: Primary Navigation
```

### 3. إنشاء الصفحة الرئيسية
```
الصفحات → إضافة جديد
العنوان: "الرئيسية"
القالب: اختر "الصفحة الرئيسية"
نشر
```

### 4. تعيين الصفحة الرئيسية
```
الإعدادات → القراءة
صفحة رئيسية ثابتة → اختر "الرئيسية"
حفظ
```

---

## 🎯 بناء صفحة باستخدام Patterns

### الطريقة السهلة:

1. **افتح محرر الصفحة**
2. **اضغط زر +**
3. **اختر "Patterns"**
4. **ابحث عن "نسق"**
5. **أضف الأنماط بالترتيب:**
   - قسم البطل ← في الأعلى
   - شبكة الخدمات ← في الوسط
   - دعوة للعمل ← في الأسفل

**🎉 خلاص! صفحتك جاهزة**
