## 🎯 نظرة عامة

قالب **نسق** هو قالب Block Theme حديث مبني على تقنية Full Site Editing في ووردبريس. تم تطويره باستخدام أفضل الممارسات لضمان:

- ✅ أداء عالي وسرعة تحميل ممتازة
- ✅ دعم كامل للغة العربية والاتجاه RTL
- ✅ تصميم متجاوب 100% على جميع الأجهزة
- ✅ سهولة التخصيص عبر محرر الكتل
- ✅ كود نظيف ومتوافق مع معايير WordPress

## 📦 التثبيت

### الطريقة الأولى: التثبيت اليدوي

1. **نسخ ملفات القالب**
   ```bash
   # انتقل إلى مجلد القوالب في ووردبريس
   cd /path/to/wordpress/wp-content/themes/

   # انسخ مجلد القالب
   cp -r /path/to/wp-nasaq-theme ./nasaq-theme
   ```

2. **تفعيل القالب**
   - انتقل إلى لوحة تحكم ووردبريس
   - من القائمة الجانبية: **المظهر** > **القوالب**
   - ابحث عن **Nasaq Theme**
   - اضغط على زر **تفعيل**

### الطريقة الثانية: التثبيت عبر لوحة التحكم

1. ضغط مجلد القالب في ملف ZIP
2. انتقل إلى: **المظهر** > **القوالب** > **أضف جديد**
3. اضغط على **رفع قالب**
4. اختر ملف ZIP وقم برفعه
5. اضغط على **تفعيل**

## 🎨 التخصيص

### تعديل الألوان

يمكنك تعديل الألوان من خلال ملف `theme.json`:

```json
{
  "settings": {
    "color": {
      "palette": [
        {
          "slug": "primary-dark-green",
          "color": "#1a4d3e",
          "name": "الأخضر الداكن الأساسي"
        }
      ]
    }
  }
}
```

أو من خلال محرر الموقع:
1. **المظهر** > **محرر الموقع**
2. **الأنماط** > **الألوان**
3. عدّل الألوان حسب رغبتك

### تعديل الخطوط

الخط الافتراضي: **Cairo** (من Google Fonts)

لتغيير الخط:
1. افتح `functions.php`
2. عدّل رابط Google Fonts في دالة `nasaq_enqueue_scripts`
3. حدّث `fontFamily` في `theme.json`

### تعديل المسافات

المسافات القياسية محددة في `theme.json`:

- **section**: 120px (للأقسام)
- **large**: 40px
- **medium**: 32px
- **small**: 20px

## 🔧 التعديلات المتقدمة

### إضافة قسم جديد

1. أنشئ ملف pattern جديد في `patterns/`:

```php
<?php
/**
 * Title: My Custom Section
 * Slug: nasaq/my-section
 * Categories: nasaq-sections
 */
?>

<!-- wp:group {"align":"full","layout":{"type":"constrained"}} -->
<div class="wp-block-group alignfull">
    <!-- أضف المحتوى هنا -->
</div>
<!-- /wp:group -->
```

2. أضف القسم في `templates/front-page.html`:

```html
<!-- wp:pattern {"slug":"nasaq/my-section"} /-->
```

### تعديل القائمة

1. **لوحة التحكم** > **المظهر** > **القوائم**
2. أنشئ أو عدّل القائمة
3. أسندها إلى **Primary Menu**

### إضافة CSS مخصص

أضف أنماط مخصصة في `assets/css/theme.css`:

```css
/* أنماطك المخصصة */
.my-custom-class {
    color: #1a4d3e;
}
```

## 🐛 استكشاف الأخطاء

### المشكلة: القالب لا يظهر في قائمة القوالب

**الحل:**
- تأكد من أن الملفات في المسار الصحيح: `wp-content/themes/wp-nasaq-theme/`
- تحقق من وجود `style.css` و `theme.json`
- تأكد من صحة ترويسة `style.css`

### المشكلة: الخطوط لا تظهر بشكل صحيح

**الحل:**
- تحقق من اتصال الإنترنت (Google Fonts)
- افحص Console في المتصفح للأخطاء
- تأكد من تحميل `functions.php` بشكل صحيح

### المشكلة: الأنماط لا تطبّق

**الحل:**
- امسح الذاكرة المؤقتة (Cache)
- تأكد من تحميل `assets/css/theme.css`
- افحص أولويات تحميل CSS في `functions.php`
