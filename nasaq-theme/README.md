# Nasaq Classic Theme - قالب نسق الكلاسيكي

قالب ووردبريس كلاسيكي قائم على الودجات (Widgets) لموقع نسق للحلول البرمجية مع دعم كامل للغة العربية (RTL).

## المميزات

✨ **قالب كلاسيكي قائم على الودجات** - كل قسم في الصفحة الرئيسية هو منطقة ودجت منفصلة
📱 **تصميم متجاوب بالكامل** - يعمل بشكل مثالي على جميع الأجهزة
🔄 **دعم RTL كامل** - مُحسّن للغة العربية
🎨 **قابل للتخصيص بالكامل** - ألوان، خطوط، ومحتوى قابل للتعديل
🚀 **أداء محسّن** - كود نظيف وسريع التحميل
♿ **سهل الوصول** - يتبع معايير WCAG
🎯 **SEO محسّن** - بنية نظيفة وصديقة لمحركات البحث

## المتطلبات

- WordPress 5.0 أو أحدث
- PHP 7.4 أو أحدث
- MySQL 5.6 أو أحدث

## التثبيت

### الطريقة الأولى: رفع يدوي

1. قم بتحميل مجلد `nasaq-theme` إلى `/wp-content/themes/`
2. من لوحة تحكم ووردبريس، اذهب إلى **المظهر → قوالب**
3. قم بتفعيل قالب "Nasaq Classic Theme"

### الطريقة الثانية: عبر لوحة التحكم

1. اذهب إلى **المظهر → قوالب → إضافة جديد**
2. انقر على **رفع قالب**
3. اختر ملف ZIP المحتوي على القالب
4. انقر على **التثبيت الآن**
5. بعد التثبيت، انقر على **تفعيل**

## الإعداد الأولي

### 1. إعداد القوائم

اذهب إلى **المظهر → قوائم**:

1. **القائمة الرئيسية** (Primary Menu):
   - أنشئ قائمة جديدة
   - أضف الصفحات: الرئيسية، الخدمات، الأعمال، من نحن، اتصل بنا
   - حددها كـ "Primary Menu"

2. **قائمة الفوتر** (Footer Menu):
   - أنشئ قائمة ثانية
   - أضف روابط سريعة
   - حددها كـ "Footer Menu"

### 2. تخصيص الألوان ومعلومات التواصل

اذهب إلى **المظهر → تخصيص → Nasaq Theme Settings**:

**الألوان:**
- اللون الأساسي: `#1a4d3e` (أخضر داكن)
- اللون الثانوي: `#ff8c42` (برتقالي)

**معلومات التواصل:**
- رقم الهاتف
- البريد الإلكتروني
- العنوان
- رقم الواتساب
- روابط التواصل الاجتماعي (فيسبوك، تويتر، لينكدإن، إنستغرام)

### 3. إضافة الودجات للصفحة الرئيسية

اذهب إلى **المظهر → تخصيص → الودجات** أو **المظهر → ودجات**:

#### القسم الأول: Hero Section
- أضف ودجت **Nasaq: Hero Section**
- املأ الحقول:
  - العنوان الرئيسي: "نحول أفكارك إلى حلول رقمية مبتكرة"
  - العنوان الفرعي: "نسق للحلول البرمجية"
  - الوصف
  - نص الزر الأساسي: "ابدأ مشروعك"
  - رابط الزر
  - الإحصائيات (سنوات الخبرة، المشاريع، العملاء، التقييم)

#### القسم الثاني: Services Section
- أضف ودجت **Nasaq: Services Section**
- الخدمات الأربعة معرّفة مسبقاً:
  - تطوير تطبيقات الويب
  - تطوير تطبيقات الجوال
  - تصميم واجهات المستخدم
  - الاستشارات التقنية

#### القسم الثالث: Portfolio Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف محتوى معرض الأعمال

#### القسم الرابع: Process Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف خطوات سير العمل

#### القسم الخامس: About Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف معلومات "من نحن"

#### القسم السادس: Testimonials Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف آراء العملاء

#### القسم السابع: Pricing Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف خطط الأسعار

#### القسم الثامن: Contact Section
- أضف ودجت **HTML مخصص** أو **نص**
- أضف نموذج الاتصال أو استخدم إضافة مثل Contact Form 7

### 4. تعيين الصفحة الرئيسية

1. اذهب إلى **الإعدادات → القراءة**
2. اختر **صفحة ثابتة**
3. حدد الصفحة الرئيسية

## مناطق الودجات المتاحة

القالب يوفر **8 مناطق ودجات** للصفحة الرئيسية:

1. **Hero Section** (`hero_section`) - قسم البطل الرئيسي
2. **Services Section** (`services_section`) - قسم الخدمات
3. **Portfolio Section** (`portfolio_section`) - قسم الأعمال
4. **Process Section** (`process_section`) - قسم سير العمل
5. **About Section** (`about_section`) - قسم من نحن
6. **Testimonials Section** (`testimonials_section`) - قسم آراء العملاء
7. **Pricing Section** (`pricing_section`) - قسم الأسعار
8. **Contact Section** (`contact_section`) - قسم اتصل بنا

## الودجات المخصصة

### 1. Nasaq: Hero Section
ودجت مخصص لقسم البطل الرئيسي يحتوي على:
- العنوان الرئيسي والفرعي
- وصف قصير
- زرين للدعوة لاتخاذ إجراء (CTA)
- 4 إحصائيات (سنوات الخبرة، المشاريع، العملاء، التقييم)

### 2. Nasaq: Services Section
ودجت مخصص لقسم الخدمات يحتوي على:
- عنوان القسم ووصفه
- 4 خدمات معرّفة مسبقاً مع أيقونات

## التخصيص المتقدم

### تعديل الألوان عبر CSS

يمكنك تعديل الألوان من ملف `assets/css/main.css`:

```css
:root {
    --primary-color: #1a4d3e;      /* اللون الأساسي */
    --primary-green: #2d6a4f;      /* الأخضر الأساسي */
    --secondary-color: #ff8c42;    /* اللون الثانوي */
    --dark-gray: #333333;          /* رمادي داكن */
    --text-gray: #666666;          /* رمادي النص */
}
```

### تعديل المسافات

```css
:root {
    --section-spacing: 120px;       /* المسافة بين الأقسام */
    --gap-large: 40px;             /* الفجوة الكبيرة */
    --gap-medium: 32px;            /* الفجوة المتوسطة */
    --gap-small: 20px;             /* الفجوة الصغيرة */
}
```

### إضافة ودجات مخصصة جديدة

لإضافة ودجت مخصص جديد، افتح ملف `inc/widgets.php` وأضف:

```php
class Your_Custom_Widget extends WP_Widget {
    public function __construct() {
        parent::__construct(
            'your_widget_id',
            __( 'Your Widget Name', 'nasaq' ),
            array( 'description' => __( 'Widget Description', 'nasaq' ) )
        );
    }

    public function widget( $args, $instance ) {
        // كود عرض الودجت
    }

    public function form( $instance ) {
        // نموذج إعدادات الودجت
    }

    public function update( $new_instance, $old_instance ) {
        // حفظ الإعدادات
    }
}

// تسجيل الودجت
function your_register_widget() {
    register_widget( 'Your_Custom_Widget' );
}
add_action( 'widgets_init', 'your_register_widget' );
```
