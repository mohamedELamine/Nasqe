# Nasaq Classic Theme - قالب نسق الكلاسيكي

قالب ووردبريس كلاسيكي قائم على الودجات (Widgets) لموقع نسق للحلول البرمجية مع دعم كامل للغة العربية (RTL).

## المميزات

✨ **8 ودجات مخصصة قابلة للتعديل بالكامل** - Services، Portfolio، Testimonials وباقي الودجات قابلة للتخصيص من واجهة الودجات
🎁 **محتوى تجريبي جاهز** - استيراد بنقرة واحدة لصفحات، مقالات، قائمة، وودجات معدّة مسبقاً مع صور احترافية
📱 **تصميم متجاوب بالكامل** - يعمل بشكل مثالي على جميع الأجهزة
🔄 **دعم RTL كامل** - مُحسّن للغة العربية
🎨 **تخصيص Typography شامل** - اختر من 10 خطوط عربية + إمكانية رفع خطوط مخصصة (woff2، woff، ttf)
📤 **رفع خطوط مخصصة** - ارفع خطك الخاص واستخدمه مباشرة في الموقع
🌈 **ألوان قابلة للتخصيص** - غيّر الألوان الأساسية والثانوية من Customizer
🚀 **أداء محسّن** - كود نظيف وسريع التحميل
♿ **Accessibility محسّن** - Skip links، ARIA labels، Focus states، Reduced motion support
🎯 **SEO محسّن** - بنية نظيفة وصديقة لمحركات البحث

## المتطلبات

- WordPress 5.0 أو أحدث

- MySQL 5.6 أو أحدث

## التثبيت

### الطريقة الأولى: رفع يدوي

1. قم بتحميل مجلد `nasaq-theme` إلى `/wp-content/themes/`
2. من لوحة تحكم ووردبريس، اذهب إلى **المظهر → قوالب**
3. قم بتفعيل قالب "Nasaq Classic Theme"

### الطريقة الثانية: عبر لوحة التحكم

1. اذهب إلى **المظهر → قوالب → إضافة جديد**
2. انقر على **رفع قالب**
3. اختر ملف ZIP المحتوي على القالب
4. انقر على **التثبيت الآن**
5. بعد التثبيت، انقر على **تفعيل**

✅ **8 ودجات مُعدّة مسبقاً** لجميع أقسام الصفحة الرئيسية:

- Services Section - قسم الخدمات مع 4 خدمات

- Pricing Section - قسم الأسعار مع 3 باقات
- Contact Section - قسم الاتصال مع معلومات التواصل

✅ **تعيين تلقائي للصفحة الرئيسية** كصفحة ثابتة (Front Page)

إذا أردت إزالة المحتوى التجريبي بعد الانتهاء من التخصيص:

3. سيتم حذف جميع الصفحات، المقالات، القائمة، والودجات التجريبية

## الإعداد الأولي

### 1. إعداد القوائم

اذهب إلى **المظهر → قوائم**:

1. **القائمة الرئيسية** (Primary Menu):
   - أنشئ قائمة جديدة
   - أضف الصفحات: الرئيسية، الخدمات، الأعمال، من نحن، اتصل بنا
   - حددها كـ "Primary Menu"

2. **قائمة الفوتر** (Footer Menu):
   - أنشئ قائمة ثانية
   - أضف روابط سريعة
   - حددها كـ "Footer Menu"

### 2. تخصيص الألوان ومعلومات التواصل

اذهب إلى **المظهر → تخصيص → Nasaq Theme Settings**:

**الألوان:**
- اللون الأساسي: `#1a4d3e` (أخضر داكن)
- اللون الثانوي: `#ff8c42` (برتقالي)

**معلومات التواصل:**
- رقم الهاتف
- البريد الإلكتروني
- العنوان
- رقم الواتساب
- روابط التواصل الاجتماعي (فيسبوك، تويتر، لينكدإن، إنستغرام)

### 2.1. تخصيص الخطوط والـ Typography

اذهب إلى **المظهر → تخصيص → Typography (الخطوط)**:

**اختيار الخط العربي:**
- Cairo - القاهرة (افتراضي)
- Tajawal - تَجَوَّل
- Almarai - المرعي
- Noto Sans Arabic
- IBM Plex Sans Arabic
- Amiri - أميري
- Lalezar - لالیزار
- Harmattan - هرمتن
- Changa - چنگہ
- Reem Kufi - ريم كوفي
- خط مخصص (Custom Font) - استخدم خطك الخاص

**رفع خط مخصص:**
لاستخدام خط مخصص:
1. اختر "خط مخصص" من قائمة الخطوط
2. أدخل اسم الخط المخصص (مثال: MyArabicFont)
3. ارفع ملفات الخط:
   - **WOFF2** (موصى به - أفضل ضغط ودعم حديث)
   - **WOFF** (للمتصفحات القديمة)
   - **TTF** (احتياطي)
4. احفظ التغييرات - سيتم استخدام الخط فوراً!

⚠️ **ملاحظة**: يجب رفع ملف واحد على الأقل (يُفضل WOFF2 للأداء الأفضل)

**أحجام الخطوط:**
- حجم الخط الأساسي: 12-22px (الافتراضي: 16px)
- حجم H1: 24-72px (الافتراضي: 48px)
- حجم H2: 20-60px (الافتراضي: 40px)
- حجم H3: 18-48px (الافتراضي: 32px)

**التحكم بالنصوص:**
- ارتفاع السطر (Line Height): 1.2 - 2.5 (الافتراضي: 1.8)
- وزن خط العناوين: 400 - 800 (الافتراضي: 700)
- وزن خط المحتوى: 300 - 600 (الافتراضي: 400)

## التخصيص المتقدم

### تعديل الألوان عبر CSS

يمكنك تعديل الألوان من ملف `assets/css/main.css`:

```css
:root {
    --primary-color: #1a4d3e;      /* اللون الأساسي */
    --primary-green: #2d6a4f;      /* الأخضر الأساسي */
    --secondary-color: #ff8c42;    /* اللون الثانوي */
    --dark-gray: #333333;          /* رمادي داكن */
    --text-gray: #666666;          /* رمادي النص */
}
```

### تعديل المسافات

```css
:root {
    --section-spacing: 120px;       /* المسافة بين الأقسام */
    --gap-large: 40px;             /* الفجوة الكبيرة */
    --gap-medium: 32px;            /* الفجوة المتوسطة */
    --gap-small: 20px;             /* الفجوة الصغيرة */
}
```

### إضافة ودجات مخصصة جديدة

لإضافة ودجت مخصص جديد، افتح ملف `inc/widgets.php` وأضف:

```php
class Your_Custom_Widget extends WP_Widget {
    public function __construct() {
        parent::__construct(
            'your_widget_id',
            __( 'Your Widget Name', 'nasaq' ),
            array( 'description' => __( 'Widget Description', 'nasaq' ) )
        );
    }

    public function widget( $args, $instance ) {
        // كود عرض الودجت
    }

    public function form( $instance ) {
        // نموذج إعدادات الودجت
    }

    public function update( $new_instance, $old_instance ) {
        // حفظ الإعدادات
    }
}

// تسجيل الودجت
function your_register_widget() {
    register_widget( 'Your_Custom_Widget' );
}
add_action( 'widgets_init', 'your_register_widget' );
```

## ميزات Accessibility (إمكانية الوصول)

القالب يتضمن تحسينات شاملة لإمكانية الوصول:

✅ **Skip to Content Link** - رابط تخطي إلى المحتوى للتنقل السريع بلوحة المفاتيح
✅ **ARIA Labels** - تسميات ARIA على جميع العناصر التفاعلية
✅ **Focus States محسّنة** - حدود واضحة عند التنقل بلوحة المفاتيح
✅ **Keyboard Navigation** - دعم كامل للتنقل باستخدام Tab و Enter
✅ **Screen Reader Support** - دعم قارئات الشاشة مع نصوص مخفية
✅ **High Contrast Mode** - دعم الوضع عالي التباين
✅ **Reduced Motion** - احترام إعدادات تقليل الحركة للمستخدمين الحساسين
✅ **Semantic HTML** - استخدام العناصر الدلالية الصحيحة (nav, main, header, footer)
